Featherly CLI.

Batch-compress JPEG, PNG, HEIC and WebP files from Terminal with the same local ImageIO pipeline as the Mac app. No uploads, no account, no server.

Included with Featherly Pro
Download Featherly CLI (.pkg) Download zip (advanced) Get Featherly Pro

Install

Recommended: download the .pkg above, double-click it, and follow the installer. It installs featherly into /usr/local/bin and is signed with a Developer ID plus notarized by Apple — no Terminal setup or Gatekeeper warning.

featherly license
featherly compress ~/Desktop/photo.jpg --quality 72

Advanced (zip): if you prefer the zip, unzip it and install manually:

sudo install -m 755 ~/Downloads/featherly /usr/local/bin/featherly
featherly license

Open Featherly once while Pro is active so it can write the local, signed CLI license token. No network access is used by the CLI. Do not run featherly itself with sudo; only the zip install command needs it.

Examples

featherly compress ~/Desktop/photo.jpg --quality 72
featherly batch ~/Pictures/shoot --out ~/Desktop/web --max 1600
featherly batch ~/Pictures --out ~/Desktop/optimized --format webp --json

Options

  • --out <folder> — output folder for folders or multiple inputs
  • --format — jpeg, png, heic or webp
  • --quality — 1–100 for JPEG, HEIC and WebP
  • --max — limit the longest side, never upscale
  • --suffix — filename suffix, default -featherly
  • --overwrite, --json, --quiet, --license <path>

Pro license
